# Esse é um post modelo

A função deste post é servir de modelo para novos posts que serão gerados. O corpo do post deve ser feito em Markdown.

Então, funções como *itálico*, **negrito** e outros padrões do Markdown podem ser usados aqui.

Também há a possibilidade de colocar carrosséis de imagens para os posts de fotos de forma fácil, mas eles devem ficar no fim do post:

[carousel]
url_01	descricao 01
url_02	descricao 02
url_03	descricao 03
url_04	descricao 04
url_05	descricao 05
[/carousel]
